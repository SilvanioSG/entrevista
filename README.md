# 📖 Sobre o Projeto

O **Assistente de Entrevistas Profissionais** é uma aplicação web interativa criada para apoiar candidatos na preparação para processos seletivos, oferecendo um ambiente de prática para entrevistas de emprego.

A proposta é proporcionar uma experiência intuitiva, permitindo que o usuário desenvolva confiança, organização das respostas e comunicação profissional diante de perguntas frequentes em entrevistas.

Mais do que uma demonstração técnica, este projeto representa a aplicação de princípios de **experiência do usuário (UX)**, **organização da informação**, **design funcional** e **transformação digital**, alinhados à melhoria de processos e ao desenvolvimento profissional.

# Objetivos

O projeto foi desenvolvido com o propósito de:

* Auxiliar candidatos na preparação para entrevistas profissionais;
* Estimular respostas estruturadas e objetivas;
* Promover maior segurança durante processos seletivos;
* Disponibilizar uma ferramenta prática e acessível diretamente pelo navegador;
* Demonstrar a aplicação de soluções digitais voltadas ao desenvolvimento profissional.

---

# Principais Funcionalidades

* Interface moderna e intuitiva;
